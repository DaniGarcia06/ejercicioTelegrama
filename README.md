# ejercicioTelegrama

Aplicación de Windows Forms que calcula el precio de un telegrama según su tipo y el número de palabras.

## Tarifas

| Tipo | Hasta 10 palabras | Cada palabra extra |
|------|-------------------|--------------------|
| Ordinario | 3 euros | 0,50 euros |
| Urgente | 6 euros | 0,75 euros |

## Compilar y ejecutar

    dotnet build
    dotnet run --project ejercicioTelegrama

## Versión

1.0.0
